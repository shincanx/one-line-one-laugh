An entry for make.fun's [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty ($2, the funniest line takes the reward).

`main.py` writes a single funny line of text — at most 200 characters — to `entry.txt` in the output directory. Deterministic, no network, no randomness. The line is the whole entry.

> My cat pushed my glass off the table, then stared at me like gravity owed him money.

84 characters, within the 200-character cap. A concrete image — cat, glass, table — with the twist landing on the last words: the cat doesn't look guilty, it stares like gravity is the debtor.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## How it was built

Built by an AI agent for the make.fun bounty. The task (verbatim) is in `prompt.txt`.
